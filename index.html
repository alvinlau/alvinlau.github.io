Showcase

Coin Greeter

Donation pages for creators, ready in seconds. Anyone can make a page without an account, add text, images and links, pick a theme, and share it. Creators sign in with a magic link to keep their pages, connect Ko-fi, and track donations from a dashboard.

How it was built: end to end with AI coding agents. I wrote the spec and the architecture notes, the agents wrote the code, and I reviewed every change, tested it and debugged what broke. A Playwright end-to-end suite covers page creation, editing, access control, the public pages and the API, so each new feature is checked against the old ones.

  • Next.js 16, React 19, TypeScript, tRPC, Tailwind
  • PostgreSQL with Prisma, Redis with BullMQ background workers
  • Auth.js magic-link sign-in, verified Ko-fi webhooks
